Overview

A single self-contained HTML file that calculates pay fixation, phased implementation, arrears, and gross salary under Bangladesh's National Pay Scale 2026. Everything runs in the browser — no backend, no build step, and no network request. Open the file and it works.

It's a real-world utility: government employees use it to sanity-check their own payslips, which raised the bar for accuracy, clarity, and honest labelling of what the tool can and can't guarantee.

Key features

  • Pay fixation (§3 & §9) from the 2015 scale to the 2026 scale across grades 1–20, including the annual-increment case.
  • Phased implementation schedule with different rates per grade band (40 / 70 / 100% and 50 / 75 / 100%).
  • Arrears (gross and net) computed on a month-and-day basis, adjusting for amounts already received under the 2024 incentive.
  • Total gross salary with allowances (house rent, medical, mobile, tiffin) and GPF / other deductions.
  • A full reference table for both the 2015 and 2026 scales.
  • Light/dark theme that follows the system setting, plus a responsive layout for mobile.
  • Inputs persisted in localStorage.

Challenges faced

  • Encoding a gazette-derived algorithm by hand

    Pay fixation is a multi-step calculation. In pure JavaScript it's easy to accumulate rounding drift, so the steps were kept explicit and each rounding point made deliberate.

  • Partial-month arrears

    Arrears run on a day basis, and the adjustment for previously received incentive money has to be subtracted correctly. Getting the edge months right took the most testing.

  • Legible Bengali on small screens

    Numerals, tables, and dense labels had to stay readable on phones without zooming, which drove a lot of the layout decisions.

  • One file, zero dependencies

    Keeping everything in a single maintainable file — with no framework and no network calls — meant organising the JS and CSS so it could still be worked on later.

Potential improvements & future plans

  • Unit tests around the calculation engine with known-good fixtures.
  • Export / print to PDF, and shareable calculation links.
  • Support for additional scales and allowance rules as they're gazetted.
  • Cross-check outputs against iBAS++ / payfixation.gov.bd and keep clearly labelling the tool as unofficial.
  • PWA / offline support so it works without a connection.
